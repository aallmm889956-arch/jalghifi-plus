جلغيفي بلس — حزمة تشغيل أولية
1) فك ضغط jalghifi_plus_bundle.zip.
2) افتح index.html باستخدام VS Code ثم شغّله عبر Live Server على المنفذ 5500.
3) قبل الاستخدام، خذ نسخة احتياطية من Supabase.
4) افتح setup.sql وشغّل محتواه مرة واحدة في Supabase > SQL Editor.
5) تأكد أن profiles.role لحسابك manager وللموظف employee. حدّثهما من SQL Editor باستخدام UUID الصحيح، ولا تسمح للعميل بتغيير role.
6) بيانات التحويل البنكي توضع في store_settings كسجل key=bank_details و value=بيانات البنك والآيبان.
ملاحظات: المفتاح داخل index.html هو Publishable key فقط؛ لا تضع service_role key في المتصفح. هذه نسخة أولية وليست تدقيقًا أمنيًا نهائيًا أو بوابة دفع. الوظائف الموسعة مثل كوبونات وتقييمات ومفضلة وإدارة الموظفين من الواجهة وإعداد OTP مخصص ليست مكتملة في هذه الحزمة. الدفع تحويل يدوي ومراجعة بشرية.
